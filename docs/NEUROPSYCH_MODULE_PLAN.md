# ADR-NP01 + خطة وحدة الطب النفسي والعصبي (Psychiatry & Neurology)

**Status:** Proposed (تصميم — لم يُبنَ بعد)
**Date:** 2026-06-05
**Deciders:** صاحب المنتج (د. أحمد) + المراجعة الهندسية
**مرجع النمط:** `docs/OBGYN_MODULE_PLAN.md` (أحدث وحدة تخصص مكتملة) + `app/Services/ModuleManager.php`

## 0) توضيح طبي أولًا (مهم)

«النفسية» و«العصبية» **تخصّصان منفصلان** عالميًا:
- **الطب النفسي (Psychiatry):** اضطرابات المزاج/القلق/الذهان/الإدمان — تشخيص DSM-5-TR/ICD-11،
  أدوية نفسية، علاج نفسي، تقييم خطر انتحار.
- **طب الأعصاب (Neurology):** أمراض الجهاز العصبي العضوية — صرع، صداع، سكتة، باركنسون،
  تصلّب متعدّد، خَرَف — فحص عصبي، EEG/EMG/تصوير، أدوية مضادّة للصرع.

يتقاطعان في «الطب النفسي-العصبي» (خرف، أعراض نفسية بعد سكتة، صداع نفسي المنشأ). الكثير
مشترك: الفحص النفسي/المعرفي، إدارة الأدوية، المواد الخاضعة للرقابة، التطبيب عن بُعد.

## 1) القرار المعماري — وحدة واحدة أم وحدتان؟

### الخيار A (موصى به): وحدة واحدة `neuropsych` + حقل `track`
وحدة واحدة «العيادة النفسية والعصبية» مع مُميِّز `track ∈ {psychiatry, neurology}` على
الطبيب وعلى كل لقاء/أداة. الواجهة تُظهر أدوات التخصّص حسب الـ track.

| البُعد | التقييم |
|---|---|
| التعقيد | متوسط — جدول واحد للملف، حقل track يفرّع العرض |
| التكرار | منخفض — MSE/الأدوية/المواد الخاضعة/التطبيب مشتركة فعليًا |
| المرونة | جيدة — عيادة بطبيب نفسي فقط أو عصبية فقط تعمل بنفس الوحدة |
| الاتساق | يطابق فكرة المستخدم («النفسية والعصبية» ككيان واحد) |

**مزايا:** تفعيل واحد، قسم Sidebar واحد، إعادة استخدام أقصى للمكوّنات المشتركة (مقاييس، MSE،
أدوية، موافقات). **عيوب:** يحتاج فلترة دقيقة بالـ track في الواجهة لئلا تختلط الأدوات.

### الخيار B: وحدتان منفصلتان `psychiatry` + `neurology`
يطابق نمط الوحدات أحادية-التخصّص الحالي (derma/dental/pediatric/obgyn).
**مزايا:** فصل نظيف، تفعيل مستقل. **عيوب:** تكرار ضخم في الكود (MSE، الأدوية، المواد
الخاضعة، التطبيب، المقاييس) → صيانة مضاعفة؛ والعيادة التي تريد الاثنين تفعّل وحدتين.

### الخيار C (مرفوض): تخصّص فرعي داخل وحدة موجودة
لا يوجد تخصّص أمّ مناسب؛ يكسر نموذج الوحدات.

### ✅ القرار (المعتمد من صاحب المنتج): **الخيار B — وحدتان منفصلتان** `psychiatry` + `neurology`.

**معالجة عيب التكرار (إلزامية):** لتفادي مضاعفة الصيانة، يُبنى **أساس سريري مشترك**
(`App\Services\NeuroPsych\…` + مكوّنات Vue مشتركة تحت `Components/Clinical/`) تستهلكه
الوحدتان: محرّك المقاييس (Scales)، مكوّن MSE، تقييم الخطر C-SSRS، إدارة الأدوية،
الموافقات. أي وحدة تفعّل أدواتها الخاصة فقط. عمليًّا = «وحدتان في الواجهة/التفعيل،
طبقة سريرية واحدة في العمق».
- `psychiatry` (الطب النفسي) — `MEDICAL_MODULES`، أيقونة/لون `#7C3AED`.
- `neurology` (طب الأعصاب) — `MEDICAL_MODULES`، أيقونة/لون `#0EA5E9`.
- عيادة بطبيب واحد تفعّل وحدة واحدة فقط؛ عيادة شاملة تفعّل الاثنتين.

## 2) قرار الخصوصية والحساسية (ADR فرعي — حرج)

سجلّات الطب النفسي **أكثر فئات البيانات حساسية**. قرارات مثبّتة:
- **تحكّم وصول مشدّد (RBAC):** ملاحظات الجلسات النفسية (psychotherapy notes) قابلة للتقييد
  حتى عن بعض الطاقم؛ صلاحية `neuropsych.sensitive.view` منفصلة.
- **Break-glass + تدقيق كامل:** كل قراءة لملف نفسي تُسجَّل في `AuditLogger` (مَن/متى).
- **موافقة منفصلة** لمشاركة الملف النفسي مع جهات خارجية (يعاد استخدام نمط الموافقات الموجود).
- **إخفاء PHI في الـ AI:** أي استدعاء AI يمرّ عبر `PhiRedactor` الموجود + موافقة المريض.
- **القُصّر والأوصياء:** قواعد وصول الوصيّ (تتقاطع مع نمط pediatric).
- لا يُخزَّن أي سرّ/مفتاح؛ المواد الخاضعة للرقابة تُسجَّل لا تُصرَف آليًا.

## 3) كتالوج الميزات — أفضل الممارسات العالمية

### 3-أ) مشترك بين التخصّصين (Core)
- **الملف النفسي/العصبي للمريض** (مستوى المريض، **مشترك** لا مقيّد بفرع): الشكوى الرئيسة،
  تاريخ المرض الحالي (HPI)، التاريخ النفسي/العصبي السابق، التاريخ العائلي، الاجتماعي،
  تعاطي المواد، التاريخ التطوّري، عوامل الخطر، الأدوية الحالية، الحساسية (يُربط بالموجود).
- **ملاحظة اللقاء** بقوالب مهيكلة: **SOAP / DAP / BIRP** (قياسية في الصحة النفسية).
- **فحص الحالة العقلية (MSE)** مهيكل: المظهر، السلوك، الكلام، المزاج، الوجدان، سيرورة
  ومحتوى التفكير، الإدراك (هلوسات)، المعرفة، الاستبصار، الحكم.
- **تقييم الخطر (حرج لسلامة المريض):** خطر الانتحار **C-SSRS**، خطر العنف/الإيذاء،
  إيذاء النفس — مع **خطة سلامة إلزامية** + **تنبيه فوري** (يعاد استخدام بانر تنبيهات
  السلامة الموجود في `Patients/Show`) عند درجة خطر مرتفعة.
- **الرعاية القائمة على القياس (Measurement-Based Care):** مكتبة مقاييس مُحقّقة يملؤها
  المريض عبر **بوابة المريض قبل الزيارة**، تتدفّق الدرجات للملف وتُرسَم اتجاهاتها زمنيًا.
- **إدارة الأدوية + الوصفات** مع **معالجة المواد الخاضعة للرقابة** (تنظيم مصر/السعودية/
  الإمارات) + **فاحص تعارض الأدوية** (يُربط بـ `DrugInteractionChecker` الموجود) +
  سجلّ تاريخ صرف المواد الخاضعة.
- **الترميز التشخيصي:** ICD-11 + DSM-5-TR (للنفسي).
- **خطة العلاج:** مشاكل/أهداف/تدخّلات/تواريخ مستهدفة + تتبّع التقدّم.
- **التطبيب النفسي عن بُعد:** يُربط بوحدة `telemedicine` الموجودة.
- **مكتبة مقاييس قابلة للضبط** + **الموافقات** (موافقة عامة، موافقة ECT/rTMS، موافقة تسجيل
  الجلسة) — يعاد استخدام نمط الموافقات.

### 3-ب) خاص بالطب النفسي (Psychiatry track)
- **المقاييس:** PHQ-9 (اكتئاب)، GAD-7 (قلق)، **C-SSRS** (انتحار)، MDQ (ثنائي القطب)،
  PCL-5 (PTSD)، Y-BOCS (وسواس قهري)، AUDIT/DAST (مواد)، ASRS (ADHD بالغين)، Vanderbilt
  (ADHD أطفال)، EPDS (اكتئاب ما بعد الولادة)، MoCA/MMSE (إدراك)، **AIMS** (خلل الحركة
  المتأخّر من مضادّات الذهان).
- **إدارة الأدوية النفسية:** SSRIs، مضادّات ذهان، مثبّتات مزاج، منبّهات، بنزوديازيبينات.
- **المراقبة الأيضية** لمضادّات الذهان (وزن/BMI/دهون/سكر/HbA1c — تحاليل مجدولة).
- **مراقبة الكلوزابين** (ANC/WBC إلزامية بنمط سجلّ) و**الليثيوم** (مستوى/كلى/درقية).
- **دورات علاجية:** ECT / rTMS / كيتامين كـ **سلسلة جلسات** (يعاد استخدام نمط جلسات
  التجميل: سلسلة + فوترة + موافقة).
- **سجلّ المواد الخاضعة للرقابة** (منبّهات، بنزو).
- **جلسات العلاج النفسي/الإرشاد** (منفصلة عن إدارة الدواء) + نمط العلاج (CBT/DBT…).

### 3-ج) خاص بطب الأعصاب (Neurology track)
- **الفحص العصبي المهيكل:** الأعصاب القحفية I–XII، الحركي، الحسّي، المنعكسات (DTRs)،
  التناسق، المشية، Romberg.
- **الصرع:** **مفكّرة نوبات** (بوابة المريض)، تصنيف ILAE لأنواع النوبات، إدارة مضادّات
  الصرع (AEDs)، **خطة طوارئ النوبة**، تقرير EEG.
- **الصداع:** تصنيف **ICHD-3**، مفكّرة صداع، MIDAS/HIT-6، علاج مُجهِض مقابل وقائي،
  فحص فرط استخدام الدواء.
- **اضطرابات الحركة:** UPDRS (باركنسون)، تقييم الرعشة.
- **السكتة:** NIHSS، mRS (رانكين المعدّل).
- **التصلّب المتعدّد:** EDSS، تتبّع الانتكاسات، إدارة DMTs.
- **المعرفي/الخَرَف:** MoCA، MMSE، رسم الساعة.
- **الإجراءات:** EMG/NCS، البزل القطني (ضغط الفتح + CSF)، EEG، **حقن البوتولينَم**
  (عضلات مستهدفة/جرعات — يعاد استخدام نمط حقن التجميل + خصم المخزون)، الحصارات العصبية.
- **تكامل التصوير:** طلب MRI/CT/EEG + إرفاق التقرير والصورة (عارض DICOM خارج النطاق
  مبدئيًا؛ إرفاق التقرير/الصورة داخل النطاق).

## 4) الدمج المعماري (يطابق نمط obgyn — **وحدتان** فوق طبقة سريرية مشتركة)

> **القرار المعتمد:** وحدتان `psychiatry` + `neurology`. الجداول/النماذج أدناه تُبنى مرّة
> واحدة في الطبقة المشتركة وتُربط بكلٍّ عبر حقل `track`/`module`، فلا تتضاعف.

- **ModuleManager:** إضافة `psychiatry` **و** `neurology` إلى `MODULES` + `MEDICAL_MODULES`.
- **المهاجرات (idempotent، additive، branch-aware):**
  - `neuropsych_profiles` (مستوى المريض، **مشترك** — بلا `branch_id`، مثل obgyn_profiles).
  - `neuropsych_encounters` (لقاء سريري — **مقيّد بفرع** + روابط فوترة/مخزون).
  - `clinical_scales` (كتالوج المقاييس) + `scale_results` (نتائج المريض — مشترك على مستوى
    المريض، يتدفّق من البوابة).
  - `risk_assessments` (C-SSRS + خطة سلامة — مشترك، حسّاس).
  - `medication_plans` + `medication_monitoring` (كلوزابين/ليثيوم/أيضي — مجدول).
  - `seizure_diary` + `headache_diary` (بوابة المريض).
  - `neuro_procedures` (EMG/LP/EEG/botox) + روابط مخزون.
  - `add_neuropsych_fields_to_doctors` (track + المؤهّلات).
  - بذر إعدادات الوحدة + التسعير + منح الصلاحيات للأدوار السريرية + صلاحية
    `neuropsych.sensitive.view` المنفصلة.
- **النماذج/المتحكّمات/الصفحات:** `Admin/Neuropsych/*` (Dashboard/Settings/Reports/Scales)
  + `Doctor/Neuropsych/*` (Dashboard/Encounter/MSE/RiskAssessment/Diaries/Procedures)
  + `Patient/Neuropsych/*` (مقاييس قبل الزيارة + مفكّرات النوبات/الصداع).
- **إعادة الاستخدام:** الفوترة (`Invoice`)، المخزون (`Supply`/SupplyTransaction للبوتوكس)،
  الموافقات (نمط CosmeticConsent)، التطبيب عن بُعد، `FormErrors`/`v-focus-trap`/
  ConfirmModal (المكوّنات المشتركة)، طبقة الـ AI (المساعد السريري + فاحص الأدوية +
  التفريغ الصوتي للجلسات بموافقة + إخفاء PHI).
- **حُرّاس الانحدار الستّة** يسري تلقائيًا على صفحات الوحدة الجديدة.

## 5) تكامل الذكاء الاصطناعي (يُبنى فوق الطبقة الموجودة)

- **مساعد سريري:** صياغة ملاحظة من MSE المهيكل (غير تشخيصي، خلف feature-flag).
- **فاحص تعارض الأدوية:** موجود — يُستدعى لحظة وصف دواء نفسي/عصبي.
- **كشف خطر استباقي:** عند إدخال درجة PHQ-9 بند 9 > 0 أو C-SSRS موجب → بانر تنبيه فوري.
- **تفريغ جلسات العلاج:** `Transcriber` الموجود — **بموافقة صريحة + إخفاء PHI** فقط.
- **تلخيص/اتجاهات المقاييس:** عرض اتجاه PHQ-9/GAD-7 عبر الزيارات.
كله: مزوّد OpenAI فقط · feature-flag لكل ميزة · إخفاء PHI · سقف تكلفة · موافقة المريض.

## 6) غير الوظيفي / الامتثال / المخاطر

- **المواد الخاضعة للرقابة:** تنظيم مصر/الخليج — تسجيل لا صرف آلي؛ سجلّ مدقّق.
- **قانون الصحة النفسية:** توثيق الإيداع غير الطوعي = **خارج نطاق** عيادة خارجية (يُذكر فقط).
- **الخصوصية:** أعلى فئة حساسية — RBAC + break-glass + تدقيق كل قراءة (راجع §2).
- **التقاطع مع pediatric:** ADHD/تطوّري للأطفال — قواعد الوصيّ.
- **المخاطر:** (1) اختلاط أدوات الـ track → فلترة صارمة + اختبارات. (2) تسريب ملاحظات
  نفسية حسّاسة → صلاحية منفصلة + اختبار وصول. (3) فوّتنا تنبيه خطر انتحار → اختبار
  إلزامي لمسار C-SSRS موجب → بانر.

## 7) خطة البناء المرحلية (كل مرحلة: بناء + pint + اختبار + commit)

- **NP0 — الأساس:** ModuleManager + مهاجرة `neuropsych_profiles` + إعدادات/صلاحيات + حقول
  الطبيب (track). تفعيل خلف العلم. اختبار عزل.
- **NP1 — اللقاء + MSE + التشخيص:** encounter + MSE مهيكل + ترميز ICD-11/DSM + خطة علاج.
- **NP2 — الرعاية القائمة على القياس:** `clinical_scales` + `scale_results` + بوابة المريض
  (PHQ-9/GAD-7 قبل الزيارة) + رسم الاتجاهات.
- **NP3 — تقييم الخطر + السلامة:** C-SSRS + خطة سلامة + **بانر التنبيه** (اختبار حرج).
- **NP4 — الأدوية + المواد الخاضعة + المراقبة:** خطط الدواء + كلوزابين/ليثيوم/أيضي +
  فاحص التعارض + سجلّ المواد الخاضعة.
- **NP5 — أدوات الأعصاب:** الفحص العصبي + مفكّرة النوبات/الصداع + EMG/LP/EEG/botox +
  إرفاق التصوير.
- **NP6 — الدورات العلاجية:** ECT/rTMS/كيتامين كسلاسل جلسات + فوترة + موافقة.
- **NP7 — التقارير + لوحة الأدمن + تكامل الـ AI** + توثيق.

## 8) القرارات (✅ محسومة من صاحب المنتج — 2026-06-05)

1. **البنية:** ✅ **وحدتان منفصلتان** `psychiatry` + `neurology` فوق طبقة سريرية مشتركة (§1).
2. **المواد الخاضعة للرقابة:** في MVP = **تسجيل/تتبّع فقط**؛ **e-prescribing كامل = مسار
   مؤجَّل منفصل** (يحتاج تكامل تنظيمي محلي مصر/الخليج + مصادقة قوية) → يُخطَّط لاحقًا.
3. **التصوير:** في MVP = **إرفاق تقرير/صورة فقط**؛ **عارض DICOM مدمج = مشروع مؤجَّل منفصل**.
4. **الحالة:** ✅ **تصميم للمراجعة فقط الآن** — لا كود حتى الموافقة على البدء.

## 9) المسارات المؤجَّلة (مشاريع منفصلة لاحقة)
- **NP-Future-1: e-prescribing للمواد الخاضعة** — ✅ **طبقة (ب) مُنفَّذة**: واجهة
  gateway عامّة + بوّابة `internal` افتراضية + بوّابات وطنية (السعودية/الإمارات/مصر)
  كـ stubs تُفعَّل عند توفّر مفتاح `controlled_rx_{code}_api_key` وتعود تلقائيًّا
  للبوّابة الداخلية. سير العمل كامل: draft → sign (MFA + sha256) → submit →
  authorized → dispensed، خاضع لصلاحية `{module}.view_sensitive` ومُدقَّق.
  **المتبقّي (طبقة أ، عند توفّر اعتمادات المنظّم):** EPCS-equivalent حقيقي +
  PDMP محلي — يُربط بإضافة driver واحد دون تغيير المتحكّم/الواجهة.
- **NP-Future-2: عارض DICOM مدمج** — ⏳ مؤجَّل (يحتاج موافقة صريحة للبدء) —
  استقبال/عرض صور MRI/CT/EEG داخل النظام.
