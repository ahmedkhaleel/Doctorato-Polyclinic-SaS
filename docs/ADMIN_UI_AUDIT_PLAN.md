- [ ] **الإجراءات أيقونات:** أزرار (تعديل/حذف/عرض/طباعة...) أيقونة SVG + tooltip، لا كلمات.
- [ ] **الأنيميشن:** ظهور متدرّج عند التحميل، انتقالات hover/focus، احترام `prefers-reduced-motion`.
- [ ] **RTL/LTR + ثنائي اللغة:** كل نص ar/en، التخطيط يعمل في الاتجاهين.
- [ ] **اكتمال الإجراءات:** كل زر/أكشن مربوط بـ route حقيقي ويعمل.
- [ ] **الباك-إند والحفظ:** الإجراء يحفظ في قاعدة البيانات ويُسترجَع بالكامل (تحقق فعلي).
- [ ] **حالات الواجهة:** loading / empty state / error / success (toast) واضحة.
- [ ] **اختصارات وروابط ذكية:** روابط سريعة للصفحات المرتبطة + أكشنات سريعة.
- [ ] **تحليل خبير UX (إلزامي لكل صفحة):** بعينٍ خبيرة، حدّد **ما الذي ينقص الشاشة** وما **الذي يجب إضافته** (حقول/فلاتر/ملخّصات/أكشنات/روابط/إحصاءات/تنبيهات)، ونفّذ الإضافات المنطقية.
- [ ] **اختبار CRUD كامل (إلزامي بعد كل صفحة):** راجع §2-أ بالأسفل — إدخال/قراءة/تعديل/حذف مُتحقَّق منه في الفرونت والباك وقاعدة البيانات.

## 2-أ. بروتوكول الاختبار الكامل لكل صفحة (بعد أي تعديل)

لا تُعتبر الصفحة منتهية إلا بعد اجتياز **الدورة الكاملة** فرونت + باك + قاعدة بيانات:

1. **العرض (Read):** الصفحة تفتح (200)، تعرض البيانات الفعلية، الفلاتر/البحث/الترقيم تعمل، الحالات الفارغة/التحميل صحيحة.
2. **الإضافة (Create):** أدخل سجلًا جديدًا من الفرونت → **تحقّق أنه حُفظ في قاعدة البيانات** (`assertDatabaseHas`) → وأنه **يظهر في القائمة/الشاشة** بعد الحفظ.
3. **التعديل (Update):** عدّل سجلًا → **تحقّق أن التغيير انعكس في DB** → وأنه ظهر في الواجهة.
4. **الحذف (Delete):** احذف سجلًا → **تحقّق أنه أُزيل من DB** (`assertDatabaseMissing` / soft-delete `deleted_at`) → واختفى من الواجهة.
5. **التحقق + الأخطاء:** القيم الخاطئة تُرفض برسائل واضحة؛ النجاح يُظهر toast.
6. **اكتمال كل أكشن:** كل زر/أيقونة على الشاشة مربوط بـ route حقيقي ويعمل (لا أزرار ميتة).
7. **آلية الاختبار:** اختبار Feature يغطّي الدورة (create→DB→update→DB→delete→DB) + `npm run build` + حُرّاس (NoEmoji/Pages) + `pint`. **بلا تصدير APP_ENV** عند تشغيل phpunit.

> **درس تشغيلي مهم:** عند تشغيل الاختبارات لا نُصدّر `APP_ENV` في الشل (يطغى على
> `testing` في phpunit.xml ويكسر الجلسة/CSRF). نستخدم `php` الصحيح (8.4.7) دون
> تصدير متغيّرات بيئة.

## 5. مقترحات تحسين تجربة المستخدم (اكتُشفت أثناء الفحص)

1. **تفعيل CommandPalette بالكامل** (Ctrl/⌘+K): تنقّل سريع + أكشنات (إنشاء مريض/حجز/فاتورة) من أي مكان.
2. **أكشنات سريعة في الجداول:** صف قابل للنقر → فتح، أزرار أيقونية للعرض/التعديل/الحذف، قائمة "..." للأكشنات الثانوية.
3. **عمليات جماعية (Bulk actions):** تحديد متعدد + حذف/تصدير/تغيير حالة جماعي حيث يلزم.
4. **بحث وفلترة فورية** موحّدة (debounce) في كل قائمة + حفظ آخر فلتر.
5. **روابط سياقية:** من الفاتورة → المريض/الزيارة؛ من المريض → حجوزاته/فواتيره/وصفاته بنقرة.
6. **حالات فارغة محفّزة:** رسالة + زر "أضف أول..." بدل جدول فارغ.
7. **Skeleton loaders** بدل التأخير الصامت.
8. **حفظ تلقائي/مؤشر حفظ** في النماذج الطويلة + تحذير عند مغادرة بتغييرات غير محفوظة.
9. **شريط أكشن لاصق** أسفل/أعلى النماذج الطويلة (حفظ دائمًا مرئي).
10. **Breadcrumbs** في الصفحات العميقة (Show/Edit).
11. **اختصارات لوحة المفاتيح** للأكشنات الشائعة (n=جديد، / =بحث، Esc=إغلاق).
12. **تحديث متفائل (Optimistic UI)** للأكشنات السريعة (تبديل حالة، نقاط...).
13. **توحيد التواريخ/الأرقام/العملة** عبر helper واحد (ar/en).
14. **Toasts موحّدة** لكل نجاح/فشل (موجودة AdminToastNotification — تعميمها).
